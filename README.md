# Akhira VR – „Al-ʿAbd · Zwei Wege“

Eine VR-Erfahrung für Meta Quest über den Weg des Menschen nach dem Tod –
vom Sterben über das Leben im Grab (Barzakh) bis zum Tag der Auferstehung –
ausschließlich nach Quran und authentischer Sunnah.

## Grundidee

Der Hadith von al-Barāʾ ibn ʿĀzib (Abu Dawud 4753, Ahmad) erzählt denselben Weg
zweimal – für den gläubigen und für den ungläubigen Diener. Der Film folgt
diesem Spiegelprinzip. Der Zuschauer ist „al-ʿAbd“, der Diener, und erlebt
alles aus eigener Sicht.
